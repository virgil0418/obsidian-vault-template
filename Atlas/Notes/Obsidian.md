[[My Plugins]]
## Obsidian快捷键配置
## 文件间跳转
- [x]  `<cmd-enter>` Follow link under cursor
- [x]  `<cmd-o>` open quick switcher
- [x]  `<cmd-> >` Navigate forward
- [x]  `<cmd<- >` Navigate back

## Pane navigation
- [x]  `<cmd-option-enter>` Open link under cursor in new pane
- [x]  `<option <- >` Focus on pane to the left
- [x]  `<option -> >` Focus on pane to the right

## Editor
- [ ]  `<cmd+j>` Toggle code
- [ ]  `<cmd+k>` Toggle highlight

## 文件内跳转
- [x]  quick switcher plugin

## 方向键改键
- `<tab-h>`
- `<tab-j>`
- `<tab-k>`
- `<tab-l>`
- 在不能用 jk 做选择的地方，只能在用方向键的地方很方便
    - Search files
    - Search headers
    - Search commands
    - Search tags
