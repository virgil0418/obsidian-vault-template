# What is AGI
let AI to achieve human-like intelligence, achieving all human intellectual capabilities.
So they can think and reason with a computational advantage.
**Should achieve**:
- abstract thinking
- common sense
- background knowledge
- transfer learning
- understanding causes and effects

# Challenge
- hardware limitation
	it's important to improves speed of AI training, by advanced hardware, or efficient software
- lack of data diversity
	one solution: GANs(generative adversarial networks) generate realistic datas to train AI

# Ethical considerations
ensure AGI is developed and used responsibly

# Technology needed
1. machine learning algorithms
2. neural network architechtures
	1. recurrent network
	2. convolutional networks
	3. transformer network
3. transfer learning（举一反三）
4. Common Sense Reasoning
5. Reinforcement Learning: achieve a goal
6. Unsupervised learning
7. Computational Resources
8. Data efficiency: learn from less data
9. Explainability: not only make intelligent decisions but can also explain them
