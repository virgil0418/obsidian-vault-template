```cpp
#include <iostream>

int main()
{
std::cout << "Hello, World!" << std::endl;
}
```


> [!warning]- 注意
> - 不要用万能头（减慢编译时间、函数名重叠、造成报错）
> - 不要用`using namespace std;`
> - 主程序不需要`return 0;`结尾
